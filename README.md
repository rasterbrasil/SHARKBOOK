# SharkBook

SaaS de agendamento online para barbearias e salões.

## Stack inicial
- React + Vite
- CSS responsivo mobile-first
- Lucide React
- Persistência inicial no `localStorage`

## Fase 1 implementada
- Onboarding em 7 etapas
- Dados da barbearia
- Tamanho da equipe
- Cadastro múltiplo de profissionais com foto obrigatória
- Catálogo de serviços sugeridos e personalizados
- Horários por dia da semana
- Upload de logo
- Portfólio com imagens
- Tela de conclusão e agendamento teste
- Tema escuro com azul de destaque
- Validações e estados vazios
